## 1. 요약 (Executive Summary)

본 보고서는 2026년 1월 23일부터 2월 13일까지 수행된 4회의 eVTOL 비행 시험에서 수집된 총 104,861건의 통신 데이터를 종합 분석한 결과를 기술한다. 분석 대상은 LTE와 Starlink 2개 통신 계층의 품질이며, 3-Layer 통합 신호 품질 체계를 적용하여 통신 안정성을 평가하였다.

### 핵심 발견사항

**1. Starlink: "연결은 되지만 속도가 극도로 낮다"**

이전 분석에서 Starlink이 "연결 안 됨"으로 보고된 것은 오류이다. 실제로는 4개 세션 모두에서 Starlink 연결률(CONNECTED)이 51.1~100.0% 범위로, 물리적 연결은 대부분 유지되고 있었다. 그러나 평균 다운로드 속도가 22.7~101.8 kbps 수준으로, 정상 기준(1 Mbps)의 2.3~10.2%에 불과하였다. Starlink은 연결되어 있으나 대역폭이 극도로 제한된 상태이다. 지연시간(Latency) 36.1~44.8ms, Ping Drop Rate 0.001~0.003으로 연결 자체의 안정성은 확인되며, 이는 의도적 대역폭 제한(In-motion 정책)과 일치하는 패턴이다.

**2. LTE SINR: 고도에 비례하여 악화되는 구조적 문제**

LTE 데이터가 유효한 3개 세션에서, SINR Poor(< 0 dB) 비율이 비행 고도와 명확한 상관관계를 보인다.

| 세션 | 평균 고도 | SINR Poor (유효 데이터 기준) |
|------|----------|---------------------------|
| 01-23 | 97.8m | 31.7% |
| 02-13 | 142.8m | 52.1% |
| 02-12 (고흥) | 240.0m | 60.4% |

RSRP(수신 전력)는 -78.7~-87.2 dBm으로 양호한 반면 SINR이 심각하게 열화되는 비대칭 패턴은, eVTOL 비행 고도에서 다수 기지국 신호가 동시 수신되면서 발생하는 셀 간 간섭(Inter-Cell Interference)의 전형적 특성이다.

**3. 3-Layer GREEN(3/3 정상) 달성률: 전 세션 약 0%**

4개 세션 전체에서 LTE와 Starlink이 동시에 정상 기준을 충족한 시점은 사실상 없었다. Starlink 다운로드 속도가 1 Mbps를 초과하는 구간이 극소수(최대 0.5%)이므로, Starlink 속도 제한이 해소되지 않는 한 GREEN 등급 달성은 구조적으로 불가하다.

**4. LTE 데이터 수집 안정성 문제**

02-05 세션은 LTE 전체 수치가 NaN으로 기록되어 LTE 모듈 수집 장애로 판단된다. 01-23 세션도 LTE 유효 데이터가 32.3%에 불과하여, 데이터 수집 안정성 확보가 필요하다.

### 종합 판단

현재 통신 구성에서 eVTOL 비행 중 안정적인 3-Layer 통합 통신을 확보하는 것은 불가능하다. Starlink의 병목은 연결이 아닌 속도이며, In-motion 정책 해제를 위한 요금제 전환이 필요하다. LTE는 고도 증가에 따른 SINR 열화가 구조적 문제이며, 외장 안테나 및 셀 선택 최적화를 통한 간섭 저감이 요구된다.

## 2. 분석 개요

### 2.1 분석 목적

eVTOL 비행 시험 중 LTE와 Starlink 통신 계층의 품질을 정량적으로 평가하고, 세션 간 비교 분석을 통해 공통 문제점과 근본 원인을 도출하여 개선 방안을 제시한다.

### 2.2 분석 방법론

#### 3-Layer 통합 신호 품질 체계

본 분석에서는 RF, LTE, Starlink 3개 통신 계층의 동시 정상 여부를 기준으로 4단계 통합 품질 등급을 적용하였다. 다만, RF/GPS 위성 수(gps_nsat) 데이터가 전 세션에서 수집되지 않아, RF 계층은 정상으로 간주하고 LTE와 Starlink 2개 계층의 품질에 따라 등급을 판정하였다.

| 등급 | 조건 | 정상 계층 수 | 의미 |
|------|------|-------------|------|
| GREEN (초록) | RF + LTE + Starlink 모두 정상 | 3/3 | 완전 이중화 통신 확보 |
| YELLOW (노랑) | 2개 계층 정상 | 2/3 | 부분 이중화, 운용 가능 |
| ORANGE (오렌지) | 1개 계층 정상 | 1/3 | 단일 통신만 가용, 위험 |
| RED (레드) | 모든 계층 비정상 | 0/3 | 통신 두절, 즉시 대응 필요 |

#### 개별 계층 정상 기준

| 통신 계층 | 정상 판단 기준 | 근거 |
|-----------|---------------|------|
| RF/GPS | GPS 위성 수 >= 10개 | 항법 정밀도 확보 기준 (데이터 미수집으로 정상 간주) |
| LTE | RSRP > -110 dBm AND SINR > 0 dB | 3GPP 최소 통신 품질 기준 |
| Starlink | CONNECTED 상태 AND 다운로드 > 1 Mbps | 실시간 데이터 전송 최소 요건 |

> **참고:** GPS 위성 수(gps_nsat) 컬럼은 전 세션에서 존재하지 않으므로, RF/GPS 계층은 별도 분석을 수행하지 않으며 정상으로 간주하였다. 따라서 3-Layer 등급은 사실상 LTE와 Starlink 2개 계층에 의해 결정된다.

#### SINR Poor 비율 산출 기준

본 보고서의 SINR Poor(< 0 dB) 비율은 **유효 데이터(Non-NaN) 대비 비율**로 산출하였다. 전체 데이터 포인트 대비가 아닌, LTE 데이터가 실제 수집된 행만을 분모로 사용한 값이다.

#### LTE 데이터 수집 장애

해당 세션의 LTE 데이터(RSRP, SINR 등) 전체 17,147건이 NaN으로 기록되었다. 이는 LTE 신호 품질 문제가 아니라 **LTE 모듈의 데이터 수집 장애**로 판단된다. Starlink 데이터는 정상 수집되었으므로, LTE 모듈 한정의 장애이다.

> **본 세션의 LTE 분석은 수행하지 않는다.** 이후 Cross-Session LTE 비교에서도 본 세션은 제외한다.

## 6. 근본 원인 분석

### 6.1 Starlink 속도 제한: In-motion 정책 추정

**추정 원인:** Starlink Residential 요금제의 이동 중 사용(In-motion) 대역폭 제한 정책

**분석 근거:**

1. **"연결 유지 + 속도 제한" 패턴:** 01-23, 02-12, 02-13 세션에서 CONNECTED 99.9~100.0%이나 다운로드 22.7~59.3 kbps로, 연결은 정상이나 대역폭만 극도로 제한된다. 이는 네트워크 장애에 의한 속도 저하가 아니라, 정책에 의한 의도적 대역폭 제한(throttling)의 전형적 패턴이다.

2. **낮은 Ping Drop Rate:** 0.001~0.003으로 매우 낮아, 위성-단말 간 통신 경로 자체에는 문제가 없음을 확인한다. 물리적 연결 품질은 양호한 상태에서 대역폭만 제한되고 있다.

3. **정상 범위의 지연시간:** 36.1~44.8ms로 Starlink의 일반적 지연시간 범위(20~60ms) 이내이며, 이 역시 연결 경로의 정상성을 뒷받침한다.

4. **Starlink 요금제별 In-motion 정책:**
   - **Residential:** 고정 주소 기반, 이동 중 사용 시 대역폭 제한 또는 연결 차단
   - **Roam (구 Portability):** 이동 사용 허용, In-motion 제한 해제
   - **In-motion (구 Maritime/Aviation):** 차량/선박/항공기 탑재 전용

5. **세션별 동작 차이 설명:**
   - 01-23, 02-12, 02-13: CONNECTED 99.9~100.0% + 속도 제한 → In-motion 탐지 후 대역폭 제한
   - 02-05: CONNECTED 51.1% + NaN 48.9% → 간헐적 연결 차단 또는 데이터 수집 불완전

> **제한사항:** 병합 데이터에 Roaming Alert 컬럼이 존재하지 않아, Roaming Alert 발생 여부를 직접 확인할 수는 없다. 그러나 "연결 정상 + 속도 극도 제한 + Latency 정상 + Ping Drop 정상"의 일관된 패턴은 In-motion 정책 대역폭 제한과 부합한다.

### 6.2 LTE SINR 열화: eVTOL 비행 고도 셀 간 간섭

**근본 원인:** eVTOL 비행 고도에서의 다중 기지국 셀 간 간섭(Inter-Cell Interference)

**분석 근거:**

1. **RSRP 양호 + SINR 열화 비대칭:** 02-13 세션에서 RSRP Excellent 56.3%인 반면 SINR Poor 52.1%이다. 수신 전력은 강하나 간섭 전력도 동시에 강한 환경을 의미한다.

2. **고도-SINR 상관관계 (정량적 근거):**

   | 평균 고도 | SINR Poor 비율 | 고도 대비 비율 |
   |----------|---------------|--------------|
   | 97.8m | 31.7% | 기준선 |
   | 142.8m (+45.0m) | 52.1% (+20.4%p) | 45m 상승당 20.4%p 증가 |
   | 240.0m (+97.2m) | 60.4% (+8.3%p) | 97m 추가 상승당 8.3%p 추가 |

   고도 100~150m 구간에서 SINR 열화 증가율이 가장 크며, 이후 포화 경향을 보인다.

3. **물리적 메커니즘:** 지상 LTE 기지국의 안테나는 하향 틸트(downtilt)로 설치되어 지상 커버리지에 최적화되어 있다. eVTOL이 비행 고도(수십~수백 미터)에 도달하면 다수 기지국의 사이드 로브(side lobe) 및 메인 로브를 동시에 수신하게 되어, 신호 전력(RSRP)은 유지되나 간섭 전력이 동시에 증가하여 SINR이 하락한다.

4. **지역별 차이:**
   - 고흥(02-12): RSRP -87.2 dBm + SINR Poor 60.4% → 기지국 저밀도 + 고고도 간섭 중복
   - 02-13: RSRP -80.3 dBm + SINR Poor 52.1% → 기지국 밀도 양호하나 고도 간섭 발생

### 6.3 LTE 데이터 수집 장애 (02-05): 모듈 수집 오류

**근본 원인:** LTE 데이터 수집 모듈의 장애 (장비/소프트웨어 오류 추정)

**분석 근거:**

1. **전체 NaN:** RSRP, SINR 등 LTE 관련 수치 전체 17,147건이 NaN으로, 특정 구간의 신호 문제가 아니라 데이터 수집 자체가 이루어지지 않은 것이다.
2. **Starlink 정상 수집:** 동일 시스템의 Starlink 데이터는 정상 수집(CONNECTED 51.1%, 속도 데이터 유효)되어, LTE 모듈만의 문제로 특정된다.
3. **이후 세션 정상화:** 02-12, 02-13 세션에서 LTE 유효율 98~99%로 정상 수집되어, 일시적 모듈 오류 또는 설정 문제로 판단된다.

## 7. 해결 방안 및 권고사항

### 7.1 Starlink: 요금제 전환을 통한 In-motion 제한 해제

| 항목 | 내용 |
|------|------|
| **문제** | Starlink 연결 유지 상태에서 대역폭 22~102 kbps로 극도 제한 |
| **추정 원인** | Residential 요금제 In-motion 정책에 의한 대역폭 제한 |
| **해결 방안** | Starlink Roam 요금제 전환 (In-motion 정책 해제) |
| **기대 효과** | 비행 중 Starlink 대역폭 확보 (수십 Mbps 이상 기대) |
| **대안** | Starlink Aviation/Maritime 요금제 (항공 전용, 비용 증가) |
| **검증 방법** | Roam 요금제 전환 후 동일 비행 경로에서 다운로드 속도 비교 시험 |

**상세 설명:**

현재 4개 세션에서 공통으로 확인된 Starlink 속도 제한은 요금제 정책에 의한 것으로 추정되며, 하드웨어/네트워크 문제가 아니다. 이 판단의 근거는 연결률 99.9~100.0%, Latency 36~45ms, Ping Drop Rate 0.001~0.003으로 연결 품질 자체에는 문제가 없다는 점이다. Roam 요금제는 이동 중 사용을 허용하며, Residential 대비 추가 비용이 발생하나 In-motion 대역폭 제한이 해제된다.

Roam 요금제 전환 후에도 속도가 개선되지 않을 경우, Starlink Aviation 요금제(항공기 전용, 고속 이동 최적화)를 검토할 필요가 있다.

### 7.2 LTE: SINR 개선 대책

| 항목 | 내용 |
|------|------|
| **문제** | eVTOL 비행 고도에서 셀 간 간섭에 의한 SINR 열화 (31.7~60.4%) |
| **근본 원인** | 고도 상승 → 다중 기지국 동시 수신 → SINR 하락 |
| **해결 방안 1** | 외장 지향성 안테나 장착 (하방 또는 특정 기지국 방향) |
| **해결 방안 2** | LTE 모듈의 셀 선택 최적화 (Band Lock, PCI Lock) |
| **해결 방안 3** | LTE 안테나 위치/방향 최적화 (기체 하부 장착, 간섭 차폐) |
| **기대 효과** | SINR 개선 → LTE 정상률 향상 → 3-Layer YELLOW/GREEN 비율 증가 |
| **검증 방법** | 동일 비행 경로에서 안테나 교체 전후 SINR 비교 시험 |

**상세 설명:**

eVTOL 비행 고도에서의 SINR 열화는 다수 기지국 신호의 동시 수신에 기인하므로, 다음의 접근이 효과적이다.

1. **지향성 안테나:** 전방향(omni) 안테나 대신 하방 지향성 안테나를 사용하면, 서빙 셀 방향의 신호만 선택적으로 수신하여 간섭을 저감할 수 있다.
2. **셀 선택 최적화:** LTE 모듈의 PCI Lock(특정 셀 고정) 또는 Band Lock(간섭이 적은 주파수 대역 선택)을 통해, 비행 중 불필요한 셀 전환과 간섭을 줄일 수 있다.
3. **안테나 위치:** LTE 안테나를 기체 하부에 장착하여, 상방에서 입사하는 원거리 기지국 간섭을 기체 구조물로 차폐하는 방법도 검토 가능하다.

### 7.3 데이터 수집 안정성 강화

| 항목 | 내용 |
|------|------|
| **문제** | 02-05 세션 LTE 전체 NaN, 01-23 세션 LTE 유효율 32.3% |

### 7.4 종합: 단계별 개선 계획

**1단계 (즉시 시행):**
- Starlink Roam 요금제 전환
- LTE 데이터 수집 모듈 점검 및 비행 전 셀프 테스트 절차 수립
- Roam 전환 후 비행 시험 1회 수행하여 효과 검증

**2단계 (단기, 1~2개월):**
- LTE 외장 지향성 안테나 시험 장착 및 SINR 비교 시험
- LTE 셀 선택 최적화(Band Lock/PCI Lock) 설정 시험
- 고도별 SINR 변화 정밀 측정 시험 (50m 단위 고도 프로파일)

**3단계 (중기, 3~6개월):**
- Multi-Network Failover 로직 구현 (LTE <-> Starlink 자동 전환)
- 비행 구간별 최적 통신 선택 알고리즘 개발
- 고흥 등 기지국 저밀도 지역 전용 통신 대책 수립 (위성 백업 강화)

## 8. 결론

2026년 1월~2월 수행된 4회의 eVTOL 비행 시험 통신 데이터(총 104,861건)를 분석한 결과, 현재 통신 구성에서 3-Layer 통합 통신 정상(GREEN) 달성률은 사실상 0%이다.

본 분석의 가장 중요한 발견은 다음 2가지이다.

**첫째, Starlink은 "연결 불량"이 아니라 "속도 제한" 상태이다.** 4개 세션에서 CONNECTED 비율 51.1~100.0%, Latency 36~45ms, Ping Drop Rate 0.001~0.003으로 연결 자체는 안정적이다. 그러나 다운로드 속도가 22.7~101.8 kbps로 정상 기준(1 Mbps)의 2~10%에 불과하다. 이는 Residential 요금제의 In-motion 정책에 의한 의도적 대역폭 제한으로 추정되며, Roam 요금제 전환으로 해결 가능성이 높다.

**둘째, LTE SINR 열화는 비행 고도와 명확한 상관관계를 보인다.** SINR Poor(< 0 dB) 비율이 평균 고도 97.8m에서 31.7%, 142.8m에서 52.1%, 240.0m에서 60.4%로, 고도 증가에 따라 일관되게 악화된다. 반면 RSRP(수신 전력)는 -78.7~-87.2 dBm으로 양호한 수준을 유지하여, 전형적인 공중 셀 간 간섭 패턴을 보인다. 이는 eVTOL 비행 환경의 구조적 문제이며, 지향성 안테나 및 셀 선택 최적화를 통한 개선이 필요하다.

3-Layer GREEN 등급 달성을 위해서는 Starlink 요금제 전환(1단계)을 통한 대역폭 확보와, LTE SINR 개선(2단계)을 통한 셀 간 간섭 저감을 병행하고, 중기적으로 Multi-Network Failover 전략을 수립하여 비행 중 통신 안정성을 확보할 것을 권고한다.

### D. 용어 정의

| 용어 | 정의 |
|------|------|
| RSRP (Reference Signal Received Power) | LTE 기준 신호 수신 전력 (dBm) |
| SINR (Signal to Interference plus Noise Ratio) | 신호 대 간섭 잡음비 (dB) |
| 3-Layer | RF/GPS, LTE, Starlink 3개 통신 계층 통합 품질 체계 |
| GREEN/YELLOW/ORANGE/RED | 3-Layer 통합 품질 등급 (3/3, 2/3, 1/3, 0/3 정상) |
| In-motion | Starlink 이동 중 사용 정책, Residential 요금제에서 대역폭 제한 |
| Inter-Cell Interference | 다수 기지국의 동일 주파수 신호에 의한 셀 간 간섭 |
| eVTOL | 전기 수직 이착륙기 (Electric Vertical Take-Off and Landing) |
| Downtilt | 기지국 안테나의 하향 경사각, 지상 커버리지 최적화를 위해 설정 |
| Side Lobe | 안테나 방사 패턴에서 메인 빔 외의 부수적 방사 영역 |
| PCI Lock | 특정 Physical Cell Identity에 고정하여 셀 전환을 방지하는 설정 |
| Band Lock | 특정 LTE 주파수 대역만 사용하도록 제한하는 설정 |
| Ping Drop Rate | 단위 시간당 핑 손실 비율, 연결 안정성 지표 |
| Throughput | 단위 시간당 실제 전송 데이터량 (대역폭과 구분) |
