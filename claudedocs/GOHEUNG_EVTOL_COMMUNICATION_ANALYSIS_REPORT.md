## 2. 서론

### 2.1 배경 및 목적

전기 수직 이착륙기(eVTOL)의 안전한 운항을 위해서는 안정적이고 신뢰할 수 있는 통신 시스템이 필수적이다. 본 비행 실증에서는 다음 세 가지 통신망을 동시에 운용하며 성능을 평가하였다.

**통신 시스템 구성**:
1. **RF/GPS**: 기본 위치 측정 및 내비게이션
2. **LTE**: 지상 기지국 기반 셀룰러 통신
3. **Starlink**: 위성 기반 광대역 인터넷 통신

이러한 다중 통신망 구성의 목적은 단일 통신 시스템 장애 시에도 안전한 운항을 보장하기 위함이다. 그러나 본 비행에서 예상치 못한 통신 성능 저하가 관측되어, 그 원인을 규명하고 개선 방안을 제시하는 것이 본 보고서의 목적이다.

### 2.2 분석 범위

**데이터 수집 범위**:

### 5.2 LTE 신호 강도 분석 (RSRP)

- 최대: 21.0 dB (우수)
- 중앙값: -1.0 dB (Fair)
- 표준편차: 4.8 dB

```python
def check_rf_ok(row):
    """RF/GPS 정상 여부 판정"""
    return row['GPS_satellites'] >= 10  # HDOP 데이터 없어 위성 개수만 사용

def check_lte_ok(row):
    """LTE 정상 여부 판정"""
    return (row['lte_rsrp'] > -110 and
            row['lte_sinr'] > 0 and
            row['lte_available'] == True)

def check_starlink_ok(row):
    """Starlink 정상 여부 판정"""
    return (row['starlink_state'] == 'CONNECTED' and
            row['starlink_downlink_throughput_bps'] > 1000000 and  # 1 Mbps
            row['starlink_ping_drop_rate'] < 0.05)  # 5%
```

**B.2 3-Layer 색상 코드 생성**

```python
def get_three_layer_color(rf_ok, lte_ok, starlink_ok):
    """3-Layer 색상 코드 판정"""
    count = sum([rf_ok, lte_ok, starlink_ok])

    if count == 3:
        return 'GREEN'    # 🟢 초록
    elif count == 2:
        return 'YELLOW'   # 🟡 노랑
    elif count == 1:
        return 'ORANGE'   # 🟠 오렌지
    else:
        return 'RED'      # 🔴 레드
```

- 검정 통계량: t = -62.3
- p-value: < 0.001
- **결론**: 귀무가설 기각, 통계적으로 유의한 음의 상관관계 존재
