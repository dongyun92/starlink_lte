================================================================================
  STEP 2  서비스 파일 업데이트
================================================================================

  !! 중요 !!
  아래 명령 블록을 복사할 때 EOF 줄이 반드시 포함되어야 합니다.
  줄 맨 앞에 공백이 없어야 합니다 (공백 있으면 인식 못 함).


  [ Pi-1 에서만 실행 — LTE 수집기 ]

  아래 블록 전체를 복사해서 터미널에 붙여넣기:
  --------------------------------------------------------------------------
sudo tee /etc/systemd/system/lte-collector.service > /dev/null << 'EOF'
[Unit]
Description=LTE Remote Collector
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/home/hanul/starlink_lte
ExecStart=/usr/bin/python3 /home/hanul/starlink_lte/lte_remote_collector_en.py --serial-port auto --exclude-ports /dev/ttyUSB0,/dev/ttyUSB1 --data-dir /home/hanul/lte-collector-data --control-port 8897 --interval 0.5 --ping-target 8.8.8.8
Restart=always
RestartSec=1
StartLimitIntervalSec=0
User=hanul
Group=hanul

[Install]
WantedBy=multi-user.target
EOF
  --------------------------------------------------------------------------

  정상 출력 예시: (아무것도 출력 안 되면 정상입니다)

  제대로 들어갔는지 확인:
    cat /etc/systemd/system/lte-collector.service

  확인 포인트: ExecStart 줄에 --ping-target 8.8.8.8 이 있으면 OK


  --


  [ Pi-2 에서만 실행 — Starlink 수집기 ]

  아래 블록 전체를 복사해서 터미널에 붙여넣기:
  --------------------------------------------------------------------------
sudo tee /etc/systemd/system/starlink-real-collector.service > /dev/null << 'EOF'
[Unit]
Description=Starlink gRPC-Web Collector
After=network-online.target
Wants=network-online.target
StartLimitIntervalSec=0

[Service]
Type=simple
WorkingDirectory=/home/hanul/starlink_lte
ExecStart=/usr/bin/python3 /home/hanul/starlink_lte/starlink/collector/grpc_web_collector.py --control-port 9201 --grpc-host 192.168.100.1 --grpc-port 9200 --interval 0.5 --data-dir /home/hanul/starlink-collect-data --ping-target 8.8.8.8
Restart=always
RestartSec=1
User=hanul
Group=hanul

[Install]
WantedBy=multi-user.target
EOF
  --------------------------------------------------------------------------

  정상 출력 예시: (아무것도 출력 안 되면 정상입니다)

  제대로 들어갔는지 확인:
    cat /etc/systemd/system/starlink-real-collector.service

  확인 포인트: ExecStart 줄에 --ping-target 8.8.8.8 이 있으면 OK

================================================================================
  STEP 4  동작 확인
================================================================================

  [ Pi-1 — LTE 로그 확인 ]

    sudo journalctl -u lte-collector.service -f

  정상 출력 예시 (1~2초마다 이런 줄이 찍혀야 합니다):
    python3[1234]: ping_rtt_ms=38.4 ping_loss=0
    python3[1234]: ping_rtt_ms=41.2 ping_loss=0
    python3[1234]: ping_rtt_ms=36.8 ping_loss=0

  ※ ping_rtt_ms 값이 보이면 정상입니다.
  ※ 로그 보기를 종료하려면 Ctrl+C 를 누르세요.


  [ Pi-2 — Starlink 로그 확인 ]

    sudo journalctl -u starlink-real-collector.service -f

  정상 출력 예시:
    python3[5678]: ping_rtt_ms=35.1 ping_loss=0
    python3[5678]: ping_rtt_ms=37.8 ping_loss=0
    python3[5678]: ping_rtt_ms=39.0 ping_loss=0

  ※ ping_rtt_ms 값이 보이면 정상입니다.
  ※ 로그 보기를 종료하려면 Ctrl+C 를 누르세요.

================================================================================
  문제 발생 시
================================================================================

  에러 로그 확인:

    [ Pi-1 — LTE ]
    sudo journalctl -u lte-collector.service --no-pager -n 30

    [ Pi-2 — Starlink ]
    sudo journalctl -u starlink-real-collector.service --no-pager -n 30

  자주 발생하는 에러:

    에러: No such file or directory: '/dev/ttyUSB2'
    원인: LTE 모뎀 USB 케이블이 빠져 있음
    조치: USB 다시 꽂고 sudo systemctl restart lte-collector.service

    에러: Connection refused (192.168.100.1:9200)
    원인: Starlink 안테나 연결 안 됨
    조치: 이더넷 케이블 확인 후 sudo systemctl restart starlink-real-collector.service

    에러: ModuleNotFoundError
    원인: Python 패키지 부족
    조치: pip3 install -r /home/hanul/starlink_lte/requirements.txt 실행 후 재시작

    에러: 셸이 > 프롬프트만 계속 나오고 멈춤
    원인: 복붙 시 EOF 앞에 공백이 들어간 것
    조치: Ctrl+C 로 취소 후 명령 블록을 다시 복붙 (공백 없이)

  해결 안 되면 에러 로그 캡처해서 공유해주세요.
